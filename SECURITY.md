# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability (such as path traversal during `.bz2` extraction or unsafe HTTP handling), please **do not** open a public issue.

Instead, report it privately via GitHub Security Advisories or contact the repository maintainers directly with:
- A description of the vulnerability
- Steps to reproduce or a proof-of-concept
- The affected version and platform

We will acknowledge your report and work on a fix as quickly as possible.
